# Fitness Booking Website

A starter React and Vite website for booking fitness classes.

## Available Scripts

- `npm install` - install dependencies
- `npm start` - start the local development server
- `npm run dev` - start the local development server
- `npm run build` - build the production site
- `npm run preview` - preview the production build locally

## Features

- Class selection and booking form
- Booking confirmation message
- Responsive page layout
- Simple, modern UI for a fitness studio

## Next steps

- Connect with a calendar or email confirmation service
